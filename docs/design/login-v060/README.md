# 0.6.0 登录页接续

背景铺满视口，右侧为420px宽的半透明浮层；窄屏表单优先，继续选择独立山海背景。玻璃层使用浅蓝底、深海军蓝文字与模糊，字段使用实底以保持可读性；背景与校徽沿用[上一轮资源和官方来源](../login-rc17/README.md)。没有人物、轮播动画或新增认证方式。

功能介绍保留真实的任务协作、知识共建和需本人确认的 AI 规划。浮层是页面内登录区域，使用原有表单及飞书入口，不额外引入弹窗焦点限制。登录错误仍保留输入，演示说明默认收起。
