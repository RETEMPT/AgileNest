# AI 项目会话与配置草稿

用户于 2026-10-07 确认先完善项目会话、插件入口和模型配置，暂不发起模型请求。从侧栏“AI 对话”进入 `/ai`，二级侧栏贴近主导航；桌面侧栏平滑伸缩，窄屏使用可用 Esc 关闭的草稿抽屉。

## 当前能力

- 输入框固定在工作区底部，高度随输入增长，上方独立滚动展示本地会话记录。记录按钮或 Ctrl / Cmd + Enter 将内容加入本地会话，Enter 换行，输入法组合回车不触发记录。
- 默认输入框缩小为 40px 文本区、768px 最大宽度，随多行增长至 144px；加号菜单使用实色面板和淡入动画，避免缩放导致文字发虚。
- 已参与项目来自公开 `identity.listMyProjects` 的账号范围查询，选择项目后在其下组织草稿；项目选择不读取任务或文件。项目失去访问权限后保留原本地草稿并标注状态，不再提供项目读取能力。
- 新建、切换、搜索、重命名、删除，切换与离开补保存；输入在停止编辑 450ms 后保存。删除需要确认，取消与 Esc 不改内容。
- 草稿最多 40 份，标题 40 字，输入与每条记录最多 6000 字，每份会话最多 20 条记录；复制包含当前会话的记录与输入。保存失败显示错误并保留输入，损坏的存储拒绝覆盖。
- 存储键 `agilenest:ai-drafts:v1:<userId>`；旧数据可读，新增可选 projectId/messages。本地内容按账号区分但不是服务端权限边界，不跨设备同步，清除浏览器数据会删除。
- 悬浮窗与完整工作区共享同一草稿与项目摘要，关闭补保存，失败阻止丢弃。主题与悬浮窗开关在个人中心直接管理。

## 模型与插件

模型设置位于输入框模型按钮、页头配置按钮和个人中心 AI 助手分区。可选择提供方、地址、模型标识、密钥环境变量名，保存/复制配置草稿与过程显示偏好。只保存变量名，不收集或发送实际密钥；配置保存不意味着模型已连接。地址只接受无凭据、无查询参数的 HTTP / HTTPS 地址。

插件入口提供四种可启用/关闭的本地技能：项目规划、任务拆解、验收整理与课题讨论。启用后可通过输入框加号插入提纲，保留已有输入。加号先列添加文件/图片、粘贴文本资料、读取与整理资料，再列本地技能和插件管理。MCP 与在线服务执行尚未接入，不伪造安装、授权或连接成功。

## 本地文件资料 · 0.4.0-rc.3

用户于 2026-10-07 要求增加文件资料和读取整理能力。本轮使用浏览器文件选择、拖放或粘贴文本表单导入，不发送至服务器或模型。单文件最多 10 MB，每份会话（包括已记录附件）最多 10 份、合计 50 MB；整批校验后写入，失败不添加部分附件、不覆盖原草稿。

- TXT、Markdown、CSV/TSV、JSON、日志和常见代码/文本格式真正读取正文，支持 UTF-8 与带 BOM 的 UTF-16，统一 Windows 换行。无法识别的编码、二进制、空文件、超额或不支持格式均说明原因。
- 文件正文独立于输入框 6000 字额度，按 100 行分页；过长单行截取显示、原文件完整保留。正文搜索统计所有匹配行、显示前 200 条并可定位；Markdown、中文编号和下划线标题提取至目录，最多 200 个标题。
- CSV/TSV 处理引号、逗号和跨行字段，统计真实行列，表格预览前 50 条数据、20 列。JSON 支持语法检查、格式化与顶层字段整理。可复制全文、复制结构、将目录加入输入框或下载原文件；输入额度不足时保留资料并说明原因。
- PNG/JPEG/WebP/GIF 提供原图预览；PDF 在支持内嵌显示的浏览器中预览，未显示时提供文件信息和下载入口。不提取 PDF/图片正文、OCR 或生成语义总结。Word/压缩包/执行文件暂不读取，Word 可另存为文本或 PDF。图片预览使用本地 Blob URL，不触发图片优化服务。
- 附件显示于输入框上方，记录后随对应本地消息保留，可仅记录附件。重新打开页面仍可读取文件；待记录附件支持移除，删除草稿同时清理其不再被引用的文件，清理失败可重试。
- 草稿与消息只保存可选 `materials` 元数据，旧草稿继续可读。正文与原文件存于 IndexedDB `agilenest-ai-materials-v1` / `materials`，复合键 `[userId,id]`，与账号草稿一致区分账号。这是浏览器本地数据组织，不代替服务端 ACL，不跨设备同步；清除浏览器数据会删除文件。

文件内容作为资料展示，不执行 HTML、脚本或其中的指令。没有新增依赖、文件上传 API、文件库、自动任务读取或模型调用。

“思考与执行过程”可展开，当前标注等待模型接入；接入后只展示服务公开返回的摘要与工具进度。没有虚构思考或模拟回复、模型请求、Agent 调度、工具执行或自动任务读写；不新增 AI SDK、AI 数据库表或 API。登录保持原样。

后续真实模型接入仍需明确服务端凭据管理、数据范围、流式失败/取消及外部工具权限，见 [ROADMAP.md](ROADMAP.md)。
