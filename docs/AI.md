# AI 对话、资料与任务规划

当前已接通真实模型 API：可以直接填写 API Key、测试连接、获取模型列表、发送对话，以及生成和确认创建项目任务。当前没有通用自主 Agent、后台自动调度、实时共同编辑或跨设备会话同步。

0.6.0 继续按账号在服务器加密保存凭据；页面账号与会话不符时拒绝请求。密钥不进入配置摘要、导出或浏览器持久化，服务端也会隐藏模型意外回显的当前连接密钥。运行包将提供商/插件设置存入本安装的 `data/private`；分享原始 ZIP 即可，本机 data 不随包发布。检查与边界见[安全记录](SECURITY-060.md)。

## 配置并测试模型

模型仅在“个人中心 → AI 助手 → 模型配置”（`/settings?section=ai`）维护。工作区、规划和浮窗中的模型设置入口先保护未保存内容，再跳转此页，不再各自提供配置表单。

首页按卡片展示最多12个 API 服务商，末尾“添加 API 服务商”打开表单；每张卡可编辑、测试、删除和“使用此服务”。新增/保存不自动切换，必须明确选择；删除当前使用项后停用模型，不自动改用其他服务。等待中的请求使用开始时的配置，切换影响后续请求。

添加或编辑时填写：

| 配置项 | 用途 |
|---|---|
| 服务预设、服务名称 | 提供常用地址，也可配置自定义服务 |
| API 地址 | 基础地址，如 https://api.example.com/v1；不填具体聊天接口路径 |
| API Key | 直接填写真实密钥，留空可保留同地址、同接口格式的已存密钥 |
| 模型名称 | 手工填写，或在地址和密钥填写后“获取模型列表” |
| 接口格式 | OpenAI Chat Completions、OpenAI Responses 或 Anthropic Messages |
| 更多选项 | 等待时间、最长回复、服务支持的推理强度 |

“保存连接”保存该服务配置；“保存并测试”先保存，再向这张卡的模型发送一条简短测试消息，不改变当前使用项。只有收到真实文字回复才显示测试成功与耗时，保存成功不等于测试成功。获取模型列表可使用当前表单或已保存服务，服务没有列表接口时仍可手工填写模型名。

配置项目参考 [CC Switch](https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/zh/2-providers/2.1-add.md)，本项目不读取或改写本机 CC Switch/Codex/Claude 配置，不复用其他应用凭据。配置文件仅导入导出本平台的非密钥字段，不宣称兼容其全部配置文件。

## 密钥与网络范围

- 服务商配置整体经服务端 AES-256-GCM 加密，以账号绑定的独立文件保存，默认目录为当前工作目录下 `.data/ai-providers`，可用 AI_PROVIDER_STORE_DIR 指定持久目录。文件名为账号哈希，使用文件锁、版本校验、临时文件同步与原子替换；并发旧版本返回409，不覆盖，损坏文件明确报错。
- 加密使用现有 AUTH_SECRET 或 NEXTAUTH_SECRET；配置无自动过期，由本人管理。明文密钥不会写入 localStorage、会话、配置导出、日志或API摘要；已有密钥不回显。只有编辑同一服务且地址/接口不变时才能留空复用密钥，更换服务、地址或协议需重新填密钥。
- 配置按服务器账号隔离，同一账号跨浏览器可读取配置摘要与选中项，但对话仍在各自浏览器。旧版未过期、属于当前账号的单连接 Cookie 在首次进入服务商管理页时迁入加密文件并清除；已有服务商文件不重复导入或恢复已删除配置。
- 备份/迁移服务器时保留加密目录和原登录 secret，两者缺一不能恢复密钥；密钥变更或文件损坏时不得用空列表覆盖原文件。`.data` 被Git和运行包复制排除，服务商私密配置不随源码/发行包分发。
- 公网服务使用 HTTPS，拒绝 URL 中的凭据/参数、重定向、受保护网络和 DNS 转私网；连接固定已验证的解析地址。校内/本机模型需管理员在服务器 AI_ALLOWED_LOCAL_ORIGINS 中明确允许完整 origin（逗号分隔）；浏览器配置不能自行放开。
- 接口使用现有登录会话，并检查同源请求；请求/响应有体积上限、超时和取消。授权、额度、地址、模型名或协议错误以中文反馈，不展示上游敏感正文。
- 不向用户索要环境变量名。服务商、地址、模型与当前使用项只由服务器账号配置管理；旧浏览器偏好的模型/API镜像在读取时清理，保留主题、提问模板及用户会话。表单编辑中的未保存内容只是临时状态，不是另一份持久配置。

### 代理虚拟 DNS 与校内地址

若域名被代理解析成 `198.18.*`，它仍属于受保护地址，不能把整个网段放开。报错会提示检查代理虚拟 DNS 或由服务器管理员仅允许已确认的完整 origin；例如 `AI_ALLOWED_LOCAL_ORIGINS=https://models.example.edu`，路径 `/api/v1` 不写入该名单。例外不关闭 HTTPS 证书验证，不接受跳转；改服务域名或端口需要重新配置。此设置只适用于明确可信的服务，不由浏览器用户自行启用。

本轮本机已为用户指定的该 origin 配置例外；不含密钥的 `/api/v1/models` 请求返回401 JSON，说明网络与TLS可达，不能据此宣称密钥、模型权限或真实生成已测试成功。其他部署没有自动继承此本机设置。

## 对话与资料

输入框发送按钮或 Ctrl / Cmd + Enter 将内容发给当前已配置的模型，普通 Enter 换行。本人消息和模型实际回复分别显示，等待时可“停止生成”；失败保留输入，不生成模拟回答。会话按账号存于浏览器，刷新可恢复；每份最多20条消息（一次对话保存问答两条）、40份会话，输入最多6000字，模型回复最多24000字。

聊天可选择“当前项目及团队共享资料”“全部可访问的团队与项目”或“仅当前对话与附件”。有项目时默认项目范围，个人会话默认仅对话；选择全部可访问可跨本人团队查询，不授予访问其他成员私密配置、私人日程或其他团队资料的权限。

模型通过受控只读工具决定搜索资料、读取文件或查询任务/里程碑，再根据真实结果回答；不取得SQL或任意文件/网络执行权。每轮与最终回答前后复核权限和版本，撤权、回收或内容变化时停止并提示重新查询。资源来源包含标题、版本与链接；目录匹配明确标记未读正文，读取后升级为实际正文位置，任务/里程碑单独列工作来源，不伪装成资料文件；未找到时明确说明。外部链接资料不自动访问网页。

明确要求查阅平台资料时，服务端先准备有界授权目录；明确要求阅读正文而模型跳过时，补充一次受控读取。旧回复中的“不能读文件”不能关闭现有工具；读取失败仍如实报告，普通聊天不强制检索。

检索有次数和大小上限，不代表穷尽整库：最多20个团队/项目范围、2000项目录、2次资料搜索、6份正文及总计24000字；任务最多6项、里程碑4项。模型决策最多4步后整理回答，整体180秒，可取消；达到边界会标识范围或截断。索引是现有名称/标签/正文检索，不是向量库或GraphRAG。

PPTX可按实际幻灯片序号读取，文本可按行继续查阅；来源显示本次实际页/行位置。一次读取只包含当前片段，返回剩余位置供后续调用，不把文件首段当作全文。

页面通过真实阶段流显示检索、读取和整理回答，不是伪造模型逐字输出；过程详情默认折叠。模型正文收到后按Markdown展示，来源可以展开查看。文本附件仍按实际正文发送，单条含附件最多30000字、整个会话请求最多120000字；超限提示选片段，不静默截断。图片/PDF目前只提供预览，不冒充图像理解或OCR。失败保留输入，已收到但本地保存失败的回复仍可复制，不自动重发。

正在请求时不能切换会话、项目或关闭浮窗；全文页面离开时提示，卸载取消请求。另一窗口修改或删除目标会话后，迟到的回复不能覆盖或复活旧会话。旧无角色记录作为本人历史输入继续可读。未发送输入、对话与资料副本保存在此设备，清除浏览器数据会删除，不等于项目中的服务端任务或资料。

## 插件库与工具开关

会话列表和加号中的“插件库”直接打开弹窗，个人AI设置也复用同一工具面板；模型连接仍只在专用模型配置页维护。插件库区分平台内置工具、快捷提问和外部MCP连接，支持查找、查看能力及逐项开关；连接详情默认收起。

内置工具包括资料检索、资料正文阅读、项目工作查询、Office文字读取和任务规划。关闭后服务端拒绝后续对应调用，不以隐藏按钮代替执行检查。原四项提问模板保留为快捷提问，不假装为文件读取或业务执行工具。插件开关和MCP连接都按账号加密保存在服务器，不由浏览器模板偏好授权。

添加MCP服务时填写可信服务名称、完整HTTP端点及可选Bearer令牌，保存后真实发现工具，再分别启用服务和需要的工具；保存、发现和启用是不同操作。令牌不回显、不写入浏览器持久存储；更改服务地址不复用旧地址的令牌或工具授权。最多8个服务、每个100个工具，工具描述、参数或注解变化后需重新核对启用。

当前连接支持MCP 2025-03-26 / 2025-06-18 Streamable HTTP的JSON及SSE响应；不启动本机命令、不安装第三方插件代码、不支持旧GET SSE、stdio或OAuth登录。只将本人明确启用且服务声明只读的工具纳入聊天；声明不是无副作用证明，应仅连接本人信任的服务。工具参数会发送到该服务，不能将平台权限视作第三方服务自身的权限保证。

“不查询平台资料”只关闭本平台的资料/项目查询；本人已启用的远程MCP工具由插件库独立控制。每次最多调用2个外部工具，单次结果最多8000字，来源显示服务名和工具名。原件不会自动上传到远程工具。

每次回答最多使用2次外部工具，文字结果限制长度，显示服务和工具来源，图片/音频返回不会被当作模型已经理解的文字。工具和平台检索的开关分别检查，调用前后配置变化会拒绝旧结果；超时或停止结束本机请求等待，不能保证第三方远端已经撤销工作。

纯文本模型可使用已提取的PPTX/DOCX文字。若要图像识别、扫描文字或语音转录，须配置实际提供该能力并返回文字的服务；MCP是连接方式，不会改变模型本身的输入能力。当前不自动把浏览器中的图片、音频原件交给远程MCP，不标记未接通能力为已启用。

## 平台共享资料库

聊天发送时可按选定范围主动检索；手动整理仍从加号打开“查阅与整理共享资料库”，主动打开后调用现有资料API，服务器重新鉴权。模型的主动工具为只读，名称/标签修改仍须在人工面板预览后明确保存。

- 查询当前项目及所属团队共享资料，按名称、标签、已保存文本搜索，支持范围筛选和分页。
- 正文按60行查阅；文档引用对应真实 revision。文件/链接仅记录读取时版本，不承诺外部内容快照。
- 引用前重新读取并核对版本，可将来源或最多1800字原文加入输入，截断有标识；超出输入额度时保留原文和当前输入。
- 可编辑资料支持名称/标签调整，先展示前后差异，再携带原 version 调用现有 PATCH；不自动修改正文、URL、分类或目录。
- 保存中禁止重复操作；冲突或未知结果先读取最新版本核对，不静默重试写入。读取后撤权/回收会拒绝引用。
- 用户主动复制进会话的摘录是本地副本，源资料后续撤权不能远程撤回副本。发送给模型前由用户选择内容并点击发送。

## 任务规划与真实任务创建

从里程碑“AI 规划任务”、聊天回复的规划入口或加号打开任务规划；已有任务简介也可作为来源。来源先预览，由本人选择加入规划目标，不覆盖已保存内容，不自动调用模型。填写目标与交付要求，点击真实生成或调整；规划模型请求只包含该目标及当前规划，不自动读取其他资料。模型输出经严格结构校验后先预览，用户采用后可继续编辑主任务、一层子任务、验收要求和“先完成哪些任务”。

父子层级表示工作拆分，任务先后表示执行顺序；校验同时考虑子任务先完成才能验收主任务的规则，拒绝无法完成的循环。手工规划最多40项，每次生成/创建最多20项；创建前每项必须有可核验的验收要求。

模型输出结构不合规时，服务端最多把校验问题交回模型修正一轮；原目标和约束保留，每次仍经过完整结构检查，不补造或直接采用无效任务。整轮最长180秒，可随时取消；修正失败保留原规划和目标。生成返回前重新检查项目访问和插件开关。

“创建项目任务”先展示明确确认，随后使用 tasks 公开契约创建待认领任务、验收要求和先后顺序，可归入来源里程碑。创建能力和任务先后设置权限沿用当前账号，不由模型决定，不自动指派他人、不改变已有任务或代替老师验收。

每批以稳定请求标识和完整规划绑定重试；部分成功保留真实任务和状态，不宣称批量回滚。创建开始后固定该批规划，重试核对已有任务，只补未完成操作；任务被认领或修改时停止覆盖。创建请求/进度按账号、项目、里程碑存于本机，清除存储后不能保证恢复同批请求，需先在项目核对已创建任务。历史损坏本地记录不覆盖，可下载原始备份。

## 已有任务的建议与确认修改

有编辑权限时，任务详情提供“AI 梳理与完善”。模型读取该任务真实标题、工作背景、验收要求及本人补充，返回整理建议、最多4个可选扩展/待确认问题与最多6段建议路线。生成不写任务，缺失事实以问题保留，不编造人员、日期或量化指标。

原标题/背景与建议并列比较，所有采纳选项默认关闭。本人勾选后查看最终将保存的内容，点击“确认应用选中修改”才调用既有任务更新契约；本轮可修改标题与工作背景，选中的扩展明确追加到背景。验收要求、负责人、日期、任务先后、状态及历史均不随此操作变更。待验收/已完成目标冻结，须先走原打回/重新打开流程；旧版本或撤权拒绝保存并保留建议，不自动重试覆盖。

## 交互式回复与项目变更建议

明确要求规划、路线或改进建议时，模型可返回受限结构化结果，页面分别展示摘要、待确认问题、路线和项目变更建议。模型只能提供数据，由本仓组件呈现，不执行生成的界面代码。普通问答继续使用Markdown；结构不完整时保留实际文本，不拼造卡片。

变更建议列出问题、方案、验收要求、影响与风险，初始为待本人审阅。选择后进入规划预览，核对并确认创建真实任务；卡片展示和打开预览本身不代表已保存或获批。已有任务的修改通过该任务详情的独立比较/确认入口执行。用户已明确本轮审批范围是项目任务、需求和规划，不包含自动修改平台源代码或部署程序。

## 可选需求澄清与验收要求检查

规划窗口中的“完善需求与验收要求（可选）”默认收起，直接生成入口保持可用；已开始创建的批次不能通过辅助功能修改。

- “帮我澄清需求”向当前配置的真实模型发送目标及当前规划，返回最多4个关键问题及原因。用户填写答复，明确选择“将答复加入目标”，然后继续生成；不会自动编造缺失的业务规则。
- “检查验收要求”针对现有规划返回最多12条问题，定位到具体任务和验收原句，说明原因，并可提供待采纳改写。本人核对后选择采用；不能自动修改真实项目任务，不形成强制评分、自动验收或成绩。
- 辅助请求只包含当前目标与规划，不自动读取整库或其他任务。保留超时、取消、权限校验与中文错误；原规划改变后不采用旧建议。无法判断的要求可仅给说明，不要求模型虚构量化指标。

里程碑“阶段进程”按目标日期展示阶段摘要。选中阶段后查看模块与任务；有子任务的主任务作为模块，子任务默认收起。模块进度按主任务及子任务中已验收项计算，子任务全部通过后仍需单独验收主任务。任务名称进入真实详情，可按权限认领、编辑、提交或验收；“AI 拆分任务”携带对应里程碑创建新规划，不自动重组已有任务。阶段排列不生成任务先后规则；已配置的先后关联在“先后顺序”中查看。

阶段列表最后的新建卡片打开里程碑弹窗；选中阶段后，任务列表最后的新增卡片打开主任务创建，自动关联阶段。模块展开后末尾可添加子任务，自动带入父任务与阶段。入口按现有创建权限和父任务状态显示；提交中禁止关闭，失败保留，成功关闭刷新，取消未保存内容须确认。新建里程碑使用稳定请求标识避免重复，错误日期明确拒绝。

## 本地文件与预览

本地文件经浏览器选择、拖放或粘贴导入，单文件10MB、每份会话最多10份、合计50MB。普通文本、图片、PDF导入本身仍留在浏览器；PPTX/DOCX会上传当前平台服务器做文字提取，界面说明此范围，提取不调用模型、不持久写入项目资料库。提取文字与原文件保存在本人浏览器，选择后点击发送才加入模型对话。

PPTX按真实幻灯片关系顺序读取文字和表格，DOCX读取正文及表格；最多提取60000字符并明确截断。图片文字、图表数据、动画、演讲者备注、页眉页脚及分页布局不在此提取范围。旧PPT、DOC、XLSX、PDF OCR未实现，需提供支持格式或文字版。Office包受路径、数量、体积、解压比、CRC、XML和取消限制，不执行宏或访问外部引用。

文本/Markdown/代码/CSV/JSON可查原文、分页、搜索和结构；项目资料库另有Markdown排版预览。CSV/TSV支持引号与跨行，JSON可查看层级，图片/PDF使用本地Blob预览；UTF-8与带BOM的UTF-16可读，编码错误明确提示。文件原件与文字存于按账号区分的IndexedDB，清理失败可重试。文件内容只作为资料，不执行其中指令。

资料库整个目录侧栏默认隐藏，可点击“展开目录”打开；分类目录、里程碑、子任务和成员贡献详情默认收起。用户主动选择目录/里程碑或搜索时展示相关路径，其余内容保持精简。模型更多选项与配置文件也默认收起。
