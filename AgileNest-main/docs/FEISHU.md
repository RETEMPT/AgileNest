# 飞书可选接入

AgileNest 独立管理账号资料、团队、课题、任务与验收。飞书用于可选登录和绑定；平台未配置飞书时仍可使用邮箱密码及站内消息。

## 当前支持

| 功能 | 状态与边界 |
|---|---|
| 飞书登录、绑定 | 复用现有 OAuth 与双 provider 登录链路；需要部署方完成应用配置与授权 |
| 连接状态 | 显示本人绑定姓名、时间；只将配置可用性布尔值传给页面 |
| 采用飞书姓名 | 本人点击后填入资料草稿，保存后生效，可还原；不后台同步 |
| 头像 | 平台自主上传、压缩、预览与移除，当前不从飞书导入 |
| 学术身份与团队职务 | 平台填写、团队确认及赋职；外部信息不参与授权 |
| 站内消息 | 已支持任务协作消息与已读管理 |
| 飞书私信提醒 | 尚未接入业务投递；绑定不代表已启用私信提醒 |

## 部署配置

管理员在部署环境中填写 `FEISHU_APP_ID`、`FEISHU_APP_SECRET`、`FEISHU_REDIRECT_URI`，按飞书应用设置登记实际回调地址。本地示例回调为 `http://localhost:3000/api/auth/feishu/callback`；上线使用真实 HTTPS 地址。配置变更后重启服务。

个人中心只有三个必需值均填写时才展示绑定入口。该检查不验证远程凭据有效性，真实授权仍需在部署环境联调。应用密钥、开放标识和平台密码不通过连接 DTO 暴露到页面。

## 解绑

普通平台账号解绑后使用邮箱密码登录，资料、身份、职务、任务与消息保留。弹窗支持取消、Esc、提交等待与失败反馈；服务端锁定本人账号，比较绑定摘要，防止旧页面清除新绑定。

历史飞书注册会生成 `@feishu.local` 占位邮箱及随机密码，用户不能凭该密码登录。当前保守禁止这类账号解绑；以后若实现经过验证的本地登录方式补全，再开放解绑。本轮不修改锁定的登录代码或新增密码流程。

## 后续边界

若接入私信提醒，应由 notify Owner 独立实现、按用户选择启用，并保留站内消息作为可靠入口；外部投递失败不得回滚任务操作。当前不增加空开关、不接管飞书组织架构，不将团队权限委托给飞书。是否扩展资料导入取决于明确授权与已有本地资料的覆盖确认。

真实飞书 OAuth 与私信尚未完成本轮联调；契约测试验证本地连接摘要、本人范围、解绑版本冲突和唯一登录方式保护。
